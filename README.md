# Airsoft League App

A full-stack web application for managing airsoft league events, teams, matches, standings, and game-day operations.

This project is being built as a real-world league management system with a professional frontend, backend API, and database-driven architecture.

---

## 🚀 Project Goals

The goal of this app is to provide an organized platform for running airsoft league events, including:

- Team registration and management
- Match scheduling
- Score tracking
- Standings and rankings
- Game formats and divisions
- Admin tools for event organizers
- Future support for live match updates and field/game-box integrations

---

## 🛠 Tech Stack

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

### Backend

- Node.js / Express (or Flask)
- REST API

### Database

- PostgreSQL (planned)

### Prerequisites

Make sure you have:

- Node.js 20+

## 💻 Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Then open:

```
http://localhost:3000
```

## 🔄 Development Workflow

Create a new branch for each feature:

```bash
git checkout main
git pull origin main
git checkout -b feature/your-feature-name
```

Commit with clear messages:

```bash
git commit -m "feat: add admin dashboard layout"
```

### Common commit types

```
feat: new feature
fix: bug fix
docs: documentation update
refactor: code restructuring
chore: maintenance task
```
